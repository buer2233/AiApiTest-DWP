# Allure 失败分析契约

仅在分析已明确选定的一次 Allure 结果运行时读取本参考。

## 输入边界

- 只读取统筹方分配的不可变分片 JSON。
- 不检查配置、环境变量、仓库文件、请求日志或未分配的结果文件。
- 不执行命令、不修改文件、不访问网络、不生成 Allure 产物。
- 除非分配输入另有说明，否则视测试环境部署版本尚未确认。

## 分类

只能选择一个类别：

- `environment`：服务可用性、部署不匹配、网络或平台条件。
- `credentials_config`：认证、授权或缺失、无效的非敏感配置。
- `dependency`：上游服务或外部前置条件失败。
- `test_data`：测试数据缺失、过期、冲突或不适用。
- `test_code`：测试初始化、断言、fixture 或实现问题。
- `product_defect`：仅在部署版本已确认且脱敏证据支持产品行为失败时使用。
- `unknown`：现有证据不足以安全分类。

## 输出

每个分配的失败指纹仅返回一个 JSON 对象，不使用 Markdown 代码围栏，也不在对象外添加说明。每个文本字段保持简洁，只使用脱敏证据；结论不能由证据证明时设置 `needs_human`。部署版本未确认时，绝不分类为 `product_defect`。
