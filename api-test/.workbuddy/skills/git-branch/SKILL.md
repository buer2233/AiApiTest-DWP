# E9+AI接口自动化测试框架：Git 分支管理（api-test-E9）

本技能是 api-test-E9 仓库分支操作的唯一入口：用自然语言完成「切换分支 / 新建分支 / 查看当前分支」。本文件自包含，不依赖任何外部 AGENTS.md。

## 作用仓库定位

- 目标仓库固定为本技能所在仓库：技能目录为 `<仓库根>/.workbuddy/skills/git-branch/`，仓库根即技能目录向上两级。所有 git 命令一律带 `-C <仓库根>` 执行，不得操作其他仓库。
- 只读 `config.json` 中的 `git` 配置块（`default_branch`、`remote_name`）；缺失时回退 `master` / `origin`。
- 绝不读取或输出 `config.json` 中的账号、密码、cookie、token；回复中只出现分支名与操作结果。

## 触发词

以下自然语言都应触发本技能：`切分支`、`切换分支`、`切换分支到 xxx`、`切到 xxx`、`新建分支`、`创建分支`、`git 分支`。同义说法（如「帮我换到 xxx 分支」「拉一个新分支 xxx」「回到主分支」）同样触发。与分支无关的请求（分析提交、执行用例、改配置、查报告）不触发本技能。

## 决策树

收到分支请求后按顺序执行，四分支覆盖全部路径：

1. **解析目标分支名**。用户消息中只接受一个分支名；出现多个候选、版本范围或与分支无关的混杂输入时，说明「一次只处理一个目标分支名」并停止。**省略分支名**（如「切分支」「切回主分支」）→ 目标回退为 `config.json` 的 `git.default_branch`（缺省 `master`）。
2. **检查未提交变更**：执行 `git -C <仓库根> status --porcelain`。输出非空 → 先向用户列出变更文件并询问处理方式（stash 暂存 / 放弃变更 / 取消操作），未获明确答复前绝不切换、绝不静默丢弃；选择 stash 时执行 `git stash push -u -m "git-branch 自动暂存"`，选择放弃时执行 `git checkout -- .` 前再次确认。输出为空 → 继续。
3. **分支已存在** → 直接切换：`git -C <仓库根> checkout <name>`（本地不存在但远端存在时，先 `git -C <仓库根> fetch <remote_name>` 再 `git checkout -b <name> <remote_name>/<name>`）。切换失败时回滚到原分支并向用户说明原因。
4. **分支不存在** → 询问确认：「分支 `<name>` 不存在，是否从 `<default_branch>` 新建？」
   - 用户确认 → `git -C <仓库根> fetch <remote_name>`（失败仅告警不阻断），然后 `git -C <仓库根> checkout -b <name> <default_branch>`。新分支基底**固定为默认分支**，不允许从其他分支拉取。
   - 用户否定 → 终止，零改动。

任何一步失败都要把仓库恢复到操作前状态（当前分支回滚、stash 弹回），并如实报告失败原因，不得伪造成功。

## 分支名校验

执行前用 `git -C <仓库根> check-ref-format --branch <name>` 校验：

- 校验不通过、含空格、含中文或含 `..`、`~`、`^`、`:`、`\` 等非法字符 → 拒绝并说明合法命名建议（如小写字母、数字、短横线、斜杠分组），零改动。
- 分支名以 `-` 开头或与 `HEAD` 同名 → 拒绝。

## 只读操作

以下查询零副作用，可直接执行，不需要确认：

- 查看当前分支：`git -C <仓库根> branch --show-current`
- 列出本地分支：`git -C <仓库根> branch --list`
- 列出远端分支：`git -C <仓库根> branch -r`

## 幂等与回滚

- 已在目标分支上时，切换请求直接回复「已在 `<name>` 分支」，不产生任何提交或变更。
- 切换类命令失败（如目标分支被删除、存在冲突路径）时，先 `git checkout <原分支>` 回滚，再报告错误；不得让仓库停留在半切换状态。

## 结果汇报

每次操作完成后用一段话回复：操作类型（切换 / 新建 / 查询）、目标分支、结果（成功 / 拒绝 / 已回滚）和当前分支。不输出凭据、不输出完整 git 日志、不执行分支操作以外的任何 git 写操作（如 push、merge、rebase、reset、删除分支）。用户要求推送或合并时，说明这不在本技能范围。
