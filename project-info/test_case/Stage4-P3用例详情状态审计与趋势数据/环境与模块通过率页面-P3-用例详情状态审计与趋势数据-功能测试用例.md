## 1. 功能测试用例 — F5 用例详情弹窗与查询

### TC-P3-F5-001 点击模块通过率打开用例详情弹窗 `[UI]`
- **关联 AC**：AC5.1
- **测试目标**：用户可从模块通过率页进入当前模块的用例详情。
- **优先级**：P0
- **前置条件**：已登录；`/modules` 存在模块快照和用例结果；模块 actions 允许详情查询。
- **测试数据**：模块 `test_gbif_case / 示例模块1`，环境“模拟测试环境”。
- **操作步骤**：
  1. 访问 `/modules?environment_id=1`。
  2. 点击模块行的 `96.00%` 通过率入口。
- **预期结果**：
  - 打开用例详情弹窗。
  - 弹窗标题包含“示例模块1”和“模拟测试环境”。
  - 首次打开时发起 `GET /api/v1/module-snapshots/{snapshot_id}/cases?status=failed&page=1&per_page=20`。
  - 未打开弹窗前不请求 cases 接口。

### TC-P3-F5-002 详情弹窗默认只展示失败用例 `[接口] [UI]`
- **关联 AC**：AC5.2
- **测试目标**：默认筛选状态为失败。
- **优先级**：P0
- **前置条件**：某模块同时存在 `failed/passed/skipped` 当前用例。
- **操作步骤**：
  1. 打开用例详情弹窗。
  2. 检查默认筛选与列表内容。
- **预期结果**：
  - 状态筛选默认选中“失败”。
  - 接口默认按 `status=failed` 查询。
  - 列表只展示 `display_status=failed` 的当前用例，不展示通过或跳过用例。

### TC-P3-F5-003 筛选通过用例 `[接口] [UI]`
- **关联 AC**：AC5.3
- **测试目标**：用户可切换到通过状态并只看通过用例。
- **优先级**：P1

  - 请求参数 `status=passed`。
  - 列表只展示 `display_status=passed` 的用例。
  - 空结果时展示“暂无通过用例”，不报错。

### TC-P3-F5-004 筛选跳过用例 `[接口] [UI]`
- **关联 AC**：AC5.4

  1. 在详情弹窗状态筛选中选择“跳过”。
  2. 点击“查询”。
- **预期结果**：
  - 请求参数 `status=skipped`。
  - 列表只展示 `display_status=skipped` 的用例。
  - 空结果时展示“暂无跳过用例”，不报错。

### TC-P3-F5-005 用例名、来源、错误类型筛选 `[接口] [UI]`

### TC-P3-F5-006 重置恢复默认失败筛选 `[UI]`
- **关联 AC**：AC5.2

- **优先级**：P1

  1. 在详情弹窗内切换到“通过”，填写筛选条件。
  2. 点击弹窗内“重置”。
- **预期结果**：
  - 弹窗状态恢复为“失败”，筛选条件清空。
  - 请求恢复 `status=failed&page=1`。
  - `/modules` 页面 URL 中原有 `environment_id`、模块页筛选和分页不被弹窗重置误清空。

### TC-P3-F5-007 用例详情字段完整展示 `[接口] [UI]`
- **关联 AC**：AC5.1、AC5.5
- **测试目标**：用例详情响应和页面字段满足需求。
- **优先级**：P0
- **操作步骤**：打开详情弹窗，检查首行用例。
- **预期结果**：
  - 接口返回 `id/node_id/case_name/case_summary/error_type/assertion_text/execution_status/display_status/error_message_summary/confirmation_result/actions`。
  - 页面展示勾选框、用例名、来源、简述、错误类型、断言、执行状态、错误摘要、确认结果。
  - 字段缺失或为空时使用 `-` 或空态文本，不出现 `undefined/null` 原样展示。

### TC-P3-F5-008 失败重试入口本阶段无副作用 `[UI]`
- **关联 AC**：AC5.6、AC5.7 阶段边界（P5 实现）

- **优先级**：P0

## 2. 权限与错误详情测试

### TC-P3-PERM-001 管理人员可查看脱敏完整错误详情 `[接口] [UI]`
- **关联 AC**：AC5.5
- **优先级**：P0

  - 展开后可看到脱敏后的 `error_message_detail`。

  - 页面不展示“查看完整详情”入口。
  - 错误摘要可见，满足定位需要但不暴露完整堆栈。

### TC-P3-PERM-003 普通成员不展示状态修改入口 `[UI]`
- **关联 AC**：AC5.8

### TC-P3-PERM-004 普通成员调用状态修改 API 返回 403 `[接口]`
