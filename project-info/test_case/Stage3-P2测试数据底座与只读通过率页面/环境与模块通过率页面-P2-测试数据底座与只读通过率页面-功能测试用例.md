## 1. 功能测试用例 — F1 模块元数据同步

### TC-P2-F1-001 首次同步生成模块记录 `[命令]`
- **关联 AC**：AC1.1
- **测试目标**：`sync_modules` 读取 `package_module.yaml`，每个顶层 key 生成一条启用模块记录。
- **优先级**：P0
- **前置条件**：`test_module` 表为空；`package_module.yaml` 含 `test_gbif_case`、`test_gbif_case_module2` 两个模块。
- **测试数据**：真实仓库 yaml（2 模块）。
- **操作步骤**：
  1. 执行 `python manage.py sync_modules`。
  2. 查询 `test_module` 全部记录。
- **预期结果**：
  - 生成 2 条记录，`package_name` 分别为 `test_gbif_case`、`test_gbif_case_module2`。
  - `module_name/module_dev/module_test` 与 yaml 一致；`is_active=true`。
  - `case_path` 为 `test_case/test_gbif_case`、`test_case/test_gbif_case_module2`。
  - 命令输出同步成功摘要（新增 2）。

### TC-P2-F1-002 负责人变更后再同步更新 `[命令]`
- **关联 AC**：AC1.2
- **测试目标**：yaml 中负责人变化，再次同步后记录更新为最新值。
- **优先级**：P1
- **前置条件**：已同步一次；构造 yaml 中 `module_dev` 由“张三”改为“张三丰”（测试用临时 yaml 或 mock 数据源）。
- **操作步骤**：
  1. 修改数据源中某模块 `module_dev`。
  2. 再次执行 `sync_modules`。
  3. 查询该模块记录。
- **预期结果**：该模块 `module_dev` 更新为新值；记录数不变（幂等 upsert，非新增）。

### TC-P2-F1-003 缺失必填字段跳过并记录原因 `[命令]`
- **关联 AC**：AC1.3
- **测试目标**：某模块缺 `module_test`（或其它必填）时，不生成不完整记录，并记录失败原因。
- **优先级**：P0
- **前置条件**：数据源含一个缺 `module_test` 的模块条目。
- **操作步骤**：
  1. 执行 `sync_modules`。
  2. 检查命令输出与 `test_module`。
- **预期结果**：
  - 该模块**不入库**（或入库失败计数+1）。
  - 命令输出包含该 `package_name` 的失败原因（缺失字段名）。
  - 其它完整模块正常同步，不受影响。

### TC-P2-E-001 重复同步幂等 `[命令]`
- **关联 AC**：AC1.1（幂等边界）
- **测试目标**：连续两次 `sync_modules` 不产生重复记录。
- **优先级**：P1
- **操作步骤**：连续执行 `sync_modules` 两次，比较记录数与 `updated_at`。
- **预期结果**：记录总数不变；无重复 `package_name`；第二次为更新或无变化，不新增。

## 2. 功能测试用例 — F3 环境通过率（API + 页面）

### TC-P2-F3-001 环境列表返回模拟测试环境 `[接口]`
- **关联 AC**：AC3.1
- **优先级**：P0
- **前置条件**：已执行 `seed_environment`；管理人员或普通成员已登录。
- **操作步骤**：携带登录 Cookie 调 `GET /api/v1/test-environments`。
- **预期结果**：200；`data` 含一项 `env_name=模拟测试环境`、`base_url=https://api.gbif.org`、`env_key=mock-gbif`。

### TC-P2-F3-002 环境汇总返回统计字段 `[接口]`
- **关联 AC**：AC3.2
- **优先级**：P0
- **前置条件**：环境存在快照（`seed_demo_metrics`）；已登录。
- **操作步骤**：调 `GET /api/v1/test-environments/{id}/summary`。
- **预期结果**：200；`data` 含 environment(id/env_name/base_url)、started_at、finished_at、duration_seconds、total/failed/passed/skipped_count、pass_rate、actions.generate_report=true。

### TC-P2-F3-003 环境无快照返回空统计 `[接口]`
- **关联 AC**：AC3.3
- **优先级**：P1
- **前置条件**：环境存在但无 `environment_snapshot`。
- **操作步骤**：调 summary 接口。
- **预期结果**：200；统计字段为 0/null，不报 500；前端据此渲染空态。

### TC-P2-ERR-001 未登录访问环境接口返回 401 `[接口]`
- **关联 AC**：F3 权限（复用 P1 鉴权）
- **优先级**：P0
- **操作步骤**：不带 Cookie 调 `GET /api/v1/test-environments` 与 summary。
- **预期结果**：401；业务码 `authentication_required`。

### TC-P2-ERR-002 环境不存在返回 404 `[接口]`
- **关联 AC**：AC3.2 异常
- **优先级**：P1
- **操作步骤**：已登录调 `GET /api/v1/test-environments/999999/summary`。
- **预期结果**：404；业务码 `environment_not_found`。

### TC-P2-F3-004 环境页展示下拉与汇总 `[UI]`
- **关联 AC**：AC3.1、AC3.2
- **优先级**：P0
- **前置条件**：已登录并有环境快照。
- **操作步骤**：访问 `/environments`；查看环境下拉与汇总区。
- **预期结果**：下拉含“模拟测试环境”；汇总展示环境、开始/结束时间、地址、通过率、运行时间；有“模块通过率”入口。

### TC-P2-E-002 环境页无快照空态 `[UI]`
- **关联 AC**：AC3.3
- **优先级**：P1
- **操作步骤**：环境无快照时访问 `/environments`。
- **预期结果**：展示“暂无执行结果”空态，无前端报错、无红色异常。

### TC-P2-F3-005 环境地址来自后端响应 `[UI]`
- **关联 AC**：AC3.4
- **优先级**：P0
- **操作步骤**：检查页面地址值来源（拦截接口响应/审查源码无硬编码 URL）。
- **预期结果**：地址渲染自 `summary`/`test-environments` 响应，前端源码不硬编码 `https://api.gbif.org`。

### TC-P2-F3-006 生成环境报告按钮占位 `[UI]`
- **关联 AC**：AC3.5
- **优先级**：P0
- **操作步骤**：点击“生成环境报告”。
- **预期结果**：提示“AI 分析报告功能后续实现”；无网络请求触发 Jenkins/后台任务；无数据写入。

## 3. 功能测试用例 — F4 模块通过率（API + 页面）

### TC-P2-F4-001 模块列表返回核心字段与分页 `[接口]`
- **关联 AC**：AC4.1
- **优先级**：P0
- **前置条件**：环境有 ≥1 模块快照；已登录。
- **操作步骤**：调 `GET /api/v1/module-snapshots?environment_id={id}&page=1&per_page=20`。
- **预期结果**：200；每条含 id、completed_at、package_name、module_name、module_dev、module_test、total_count、failed_count、pass_rate、duration_seconds、actions；`meta` 含 total/page/per_page/total_pages。

### TC-P2-F4-002 通过率公式正确 `[接口]`
- **关联 AC**：AC4.2
- **优先级**：P0
- **前置条件**：构造模块快照 `total_count=100, failed_count=4`。
- **操作步骤**：调模块列表接口。
- **预期结果**：该模块 `pass_rate=0.96`（前端展示 96.00%）。

### TC-P2-F4-003 模块名称/包名/模块测试筛选 `[接口]`
- **关联 AC**：AC4.1 筛选
- **优先级**：P1
- **操作步骤**：分别用 `module_name`、`package_name`、`module_test` 模糊筛选。
- **预期结果**：仅返回匹配模块；`meta.total` 相应减少。

### TC-P2-F4-004 通过率上限筛选 `[接口]`
- **关联 AC**：AC4.1 筛选
- **优先级**：P1
- **操作步骤**：调 `?pass_rate_lte=90`。
- **预期结果**：仅返回 `pass_rate<=0.90` 的模块。

### TC-P2-ERR-003 排序字段非白名单返回 422 `[接口]`
- **关联 AC**：AC4.1 异常
- **优先级**：P1
- **操作步骤**：调 `?sort=drop_table`。
- **预期结果**：422 `validation_error`；不按非法字段排序，避免注入。

### TC-P2-ERR-004 环境参数缺失/无效返回 422 `[接口]`
- **关联 AC**：AC4.1 异常
- **优先级**：P0
- **操作步骤**：调不带 `environment_id`，及 `environment_id=999999`。
- **预期结果**：422 `validation_error`（缺失/无效环境）。

### TC-P2-E-003 分页越界返回 422 `[接口]`
- **关联 AC**：AC4.1 边界
- **优先级**：P1
- **操作步骤**：调 `?per_page=101`、`?page=0`。
- **预期结果**：422（复用 P1 分页校验：per_page 1-100、page≥1）。

### TC-P2-E-004 零用例不除零 `[接口]`
- **关联 AC**：AC4.2 边界
- **优先级**：P1
- **前置条件**：构造模块快照 `total_count=0`。
- **操作步骤**：调模块列表接口。
- **预期结果**：`pass_rate=0`（或约定值），接口不抛除零错误、不返回 500。

### TC-P2-E-005 后置操作 actions 统一 false `[接口]`
- **关联 AC**：AC4.1 契约切片
- **优先级**：P1
- **操作步骤**：检查响应 `actions`。
- **预期结果**：`failed_rerun/module_rerun/trend_7d/trend_30d/jenkins_tasks` 均为 `false`（P2 不开放后置能力）。

### TC-P2-ERR-005 未登录访问模块接口返回 401 `[接口]`
- **关联 AC**：F4 权限
- **优先级**：P0
- **操作步骤**：不带 Cookie 调模块列表接口。
- **预期结果**：401 `authentication_required`。

### TC-P2-F4-005 模块页展示核心字段 `[UI]`
- **关联 AC**：AC4.1
- **优先级**：P0
- **操作步骤**：访问 `/modules`（默认选中唯一环境）。
- **预期结果**：表格展示日期、用例包名、模块名称、模块开发、模块测试、通过率、执行时间。

### TC-P2-F4-006 通过率展示格式与语义色 `[UI]`
- **关联 AC**：AC4.2
- **优先级**：P1
- **操作步骤**：查看 `total=100,failed=4` 模块行。
- **预期结果**：展示 `96.00%`；通过率按高/低映射 DESIGN 语义色（success/warning/error），珊瑚不替代状态色。

### TC-P2-F4-007 模块页筛选与分页交互 `[UI]`
- **关联 AC**：AC4.1
- **优先级**：P1
- **操作步骤**：输入筛选条件查询；点击上/下一页。
- **预期结果**：列表按筛选刷新；分页按 `meta` 正确禁用边界按钮；首页禁用上一页、末页禁用下一页。

### TC-P2-E-006 模块页无数据空态 `[UI]`
- **关联 AC**：AC4.1 边界
- **优先级**：P1
- **操作步骤**：环境无模块快照时访问 `/modules`。
- **预期结果**：展示空态，不报前端错误。
