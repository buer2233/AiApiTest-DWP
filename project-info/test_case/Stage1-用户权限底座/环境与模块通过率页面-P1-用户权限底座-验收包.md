## 5. 实现摘要

- **后端**：新增 Django/DRF P1 账号体系、Cookie JWT 鉴权、用户和邀请码模型、登录/退出/当前用户/注册/用户列表/邀请码管理接口、初始化管理员命令。
- **前端**：新增 Vue 3/Vite/TypeScript 工程、Cookie 鉴权路由守卫、登录/注册 Access Split Gate 路由拆分、受保护布局、用户列表、邀请码管理、403 反馈和 401 重定向。
- **本次验收缺陷修复**：登录失败统一 `账户或密码错误`；注册弱密码返回 `密码需 8-64 位，至少包含字母和数字` 与缺失项；邀请码明文复制提供 Clipboard API 和 textarea 兜底；已使用邀请码明确提示 `邀请码已经被使用。`；中文账号返回 `invalid_username` 并在前端本地拦截；密码不一致优先提示 `两次输入的密码不一致。`。
- **关键设计决策**：
  - Cookie 名固定为 `authToken`；`HttpOnly; SameSite=Lax; Path=/`；`Secure` 由环境变量启用。
  - `POST /api/v1/auth/login` 和 `POST /api/v1/auth/register` 是公开接口，其余 P1 API 均要求有效 Cookie。
  - 邀请码数据库只保存哈希，明文只在创建响应和前端创建弹窗本次展示。
  - 注册成功不自动登录。
  - 复合原型图不能整屏复刻到单个 route：`/login` 只展示登录，`/register` 只展示注册，登录后受保护页面只在鉴权成功后展示。
  - 前端 API 使用 `/api/v1` 相对路径或 `VITE_API_BASE_URL`，不写死本机端口。
- **独立对抗审查结论**：第一轮 4 个 Important 和 1 个 Minor、二次审查 1 个 Important 和 2 个 Minor 均已修复；缺失/空密码字段、65 位密码边界、OpenAPI schema、前端 UI 证据和证据脱敏均已纳入回归。
