## 1. 登录成功默认跳转

### TC-S7-F1-001 直接打开登录页成功登录后进入环境管理页 `[UI]`
- **关联 AC**：AC-S7-1.1、AC-S7-1.2
- **优先级**：P0
- **前置条件**：mock `POST /api/v1/auth/login` 返回管理人员；mock `GET /api/v1/auth/me` 可返回当前用户。
- **步骤**：
  1. 打开 `/login`。
  2. 输入正确账号和密码。
  3. 点击“进入平台”。
- **预期结果**：
  - URL 为 `/environments`。
  - 页面显示登录后受保护布局。
  - 页面不依赖 `/dashboard` 作为默认首屏。

## 2. 显式 redirect 优先级

### TC-S7-F2-001 直接访问受保护 URL 后登录仍回到原目标 `[UI]`
- **关联 AC**：AC-S7-2.1、AC-S7-2.2
- **优先级**：P1
- **前置条件**：用户未登录；mock 登录接口成功。
- **步骤**：
  1. 打开 `/dashboard`。
  2. 确认被带回 `/login` 且存在 `redirect=/dashboard`。
  3. 输入正确账号和密码并登录。
- **预期结果**：
  - 登录成功后 URL 为 `/dashboard`。
  - 该行为证明显式 redirect 优先于默认 `/environments`。

## 3. 根路径默认入口

### TC-S7-F3-001 已登录用户访问根路径进入环境管理页 `[UI]`
- **关联 AC**：AC-S7-3.1
- **优先级**：P1
- **前置条件**：mock 当前用户已登录。
- **步骤**：
  1. 打开 `/`。
  2. 等待路由守卫和 redirect 完成。
- **预期结果**：
  - URL 为 `/environments`。

### TC-S7-F3-002 未登录用户访问根路径最终登录目标为环境管理页 `[UI]`
- **关联 AC**：AC-S7-3.2
- **优先级**：P1
- **前置条件**：mock 当前用户未登录。
- **步骤**：
  1. 打开 `/`。
  2. 等待路由守卫处理。
- **预期结果**：
  - URL 为 `/login`，查询参数中的 `redirect` 指向 `/environments` 或登录成功后默认进入 `/environments`。
