## 2. 视觉与交互基线

- **页面气质**：企业级自动化测试管理后台，高密度、可扫描、克制，不做营销页。
- **主画布**：warm cream canvas `#faf9f5`，表格/弹窗 surface 使用 `#efe9de`、`#f5f0e8` 和 hairline `#e6dfd8`。
- **主操作**：coral primary `#cc785c`；hover/active 使用 `#a9583e`。状态色不得混用 coral：失败 `#c64545`，通过 `#5db872`，跳过/警告 `#d4a017`。
- **深色产品面**：错误详情、脱敏堆栈、node id 预览可用 dark product surface `#181715`，文字使用 `#faf9f5` / `#a09d96`。
- **字号层级**：弹窗标题 18-22px，表格/表单 14px，说明/计数 12-13px；不使用 hero 级大字。
- **间距与圆角**：4/8px 节奏；按钮、输入、分段控件圆角 8px；弹窗和状态卡不超过 12px。
- **可访问性**：所有按钮可键盘聚焦；图表必须有文本摘要和同源表格；状态不只靠颜色表达，必须配文字标签。

## 6. 用例详情弹窗规格

- **打开方式**：点击模块通过率、模块行详情入口；弹窗打开时设置 `status=failed&page=1&per_page=20`。
- **标题**：`{module_name} / {environment_name} / 用例详情`，并显示默认失败筛选提示。
- **筛选区**：状态分段控件 `失败 / 通过 / 跳过`；输入项 `用例名`、`来源 node id`、`错误类型`；按钮 `查询`、`重置`。
- **桌面表格列**：勾选框、用例名、来源、简述、错误类型、断言、执行状态、错误摘要、确认结果、操作。
- **列表层级硬约束**：P3 的“用例详情”是当前模块下的用例结果列表弹窗，不是单条用例详情页；不得复刻候选 01 的单条详情页式信息架构为主页面。列表必须保留状态筛选、组合筛选、分页和多行结果。
- **移动端布局**：表格转卡片；node id 使用等宽字体并允许截断/复制；筛选折叠进“筛选”面板。
- **权限差异**：admin 显示“查看详情”和“修改状态”；member 不显示完整详情入口和状态修改入口。
- **空态**：按当前状态展示“暂无失败用例 / 暂无通过用例 / 暂无跳过用例”。
- **错误态**：展示接口错误码对应的中文说明和“重新加载”，不清空模块页原筛选。

## 7. 状态修改确认弹窗规格

- **触发**：仅 admin 在当前用例行点击“修改状态”。
- **字段**：当前状态、目标状态、修改原因、审计预览、影响统计摘要。
- **目标状态**：`failed/passed/skipped`；当前状态对应选项禁用。
- **原因**：1-512 字必填；空值前端阻止提交，后端仍需返回 422。
- **提交中**：保存按钮 loading，取消按钮可禁用；避免重复提交。
- **成功反馈**：关闭确认弹窗，刷新当前 cases、模块统计和环境摘要；显示“状态已更新，审计记录已写入”。
- **失败反馈**：409 同状态、409 archived、422 validation、403 admin_required 均在弹窗内展示可恢复错误；不显示成功统计。

## 8. 趋势弹窗规格

- **触发**：模块行 `7天趋势`、`30天趋势` 按钮；只有 `actions.trend_7d/trend_30d=true` 才启用。
- **标题**：`{module_name} / {environment_name} / 近 {days} 天趋势`。
- **图表**：使用轻量 SVG polyline/circle/text，不新增图表依赖；y 轴为通过率百分比，x 轴为后端返回 `run_date`。
- **文本摘要**：有数据时展示区间首末通过率变化；无数据时展示“暂无趋势数据”。
- **空态**：当 `series=[]` 时不渲染空折线图；展示“暂无趋势数据”“当前模块在所选窗口内没有历史运行记录”，保留窗口切换入口和空趋势表格，表格行显示“无历史记录”。
- **趋势表格**：日期、运行类型、总数、失败、跳过、通过率、执行时间；数据与 SVG 同源。
- **错误态**：趋势接口失败显示“趋势数据加载失败，请稍后重试”和“重新加载”按钮。

## 10. 前端开发冻结说明

- 前端不得把候选图 05 的“执行列表/趋势看板”实现到 P3；P3 只在 `/modules` 上新增弹窗能力。
- 前端不得把候选图标题、说明线、框线、对比备注实现到产品 DOM。
- 前端不得把候选 01 的单条详情页式信息架构作为 P3 主结构；用例详情弹窗必须是列表+筛选+分页。
- 前端不得新增 Jenkins、报告、重试执行 API；禁用入口点击不得产生写请求。
- 前端不得预取所有模块 cases/trend；只有用户点击详情或趋势后请求对应 API。
- 前端必须在弹窗关闭时销毁弹窗内容，避免关闭后仍能定位到用例文本。
- 前端必须使用后端返回字段，不硬编码 seed 示例用例名、node id、环境名或模块名。
- 前端不得实现补充趋势空态图中的“数据每 5 分钟自动更新”文案，P3 没有自动刷新需求。
