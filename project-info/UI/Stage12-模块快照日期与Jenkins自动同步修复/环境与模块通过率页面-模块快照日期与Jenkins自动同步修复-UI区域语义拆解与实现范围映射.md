## 4. 前端实现范围映射

| 用户路径 | Vue route | 组件 / 区域 | 用户动作 | 数据来源 | Playwright 验收点 | 实现动作 |
| --- | --- | --- | --- | --- | --- | --- |
| 查看模块日期与执行时间 | `/modules` | 既有模块表格 | 选择环境或刷新页面 | `GET /api/v1/module-snapshots` | Daily / 模块重试完成后显示 Jenkins 实际完成日期和最新执行时间 | 不改前端源码 |
| 查看 30 天趋势 | `/modules` | `ModuleTrendDialog.vue` | 点击“30天趋势” | `GET /api/v1/module-snapshots/{id}/trend?days=30` | 窗口以请求当天结束，可见 7 月 11/12 日真实记录；无记录日期不补零 | 不改前端源码 |

## 5. 状态与边界校准

- 加载态、空态、错误态、权限态沿用现有组件，不增加新的视觉状态。
- 日期按浏览器当前 locale 展示，但数据源必须是带时区的 `completed_at`；前端不得使用本地当前时间覆盖接口值。
- 趋势最多展示接口返回的 7 或 30 天真实记录；同日优选规则由后端执行，前端不二次去重。
- 桌面与 390px 移动端布局沿用 Stage11 已验收断点，修复不得造成表格、趋势图或弹窗溢出。
- 页面不展示 Jenkins API 地址、queue id、RUN_ID、artifact 路径、Cookie、token 或 worker 命令输出。

## 6. 覆盖校准结论

- 正常场景：Daily、模块重试完成后，列表日期、执行时间、任务状态和趋势自动反映新结果。
- 异常场景：queue 404 可恢复时页面不出现 503；Jenkins 真正不可用时保留既有错误反馈。
- 边界场景：无真实执行的日期不生成趋势点；失败重试不改模块日期和执行时间。
- 权限场景：同步接口仍仅管理员可用，普通用户只读取既有页面数据。
- 范围冻结：Stage12 不进入任何 Vue 代码变更；若实现过程中出现新增 DOM、路由、按钮或说明文字，必须退回 UI 阶段重新冻结。
