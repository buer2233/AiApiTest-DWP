# 环境与模块通过率页面-Jenkins依赖复用与趋势图修复-UI区域语义拆解与实现范围映射

## 1. 原型基线

- 复用现有模块通过率页和 `ModuleTrendDialog.vue` 弹窗，不新增页面或路由。
- 保持现有暖白画布、hairline 边框、8px 圆角、主品牌折线色和紧凑表格。
- 本轮只增强趋势图的信息表达，不改模块列表、操作按钮和趋势表格字段。

## 2. 区域语义拆解

| 区域 | 内容 | 处理方式 | 不进入 DOM 的标注 |
| --- | --- | --- | --- |
| R1 | 弹窗标题与区间摘要 | 当前弹窗直接展示 | 无 |
| R2 | 通过率折线图 | 当前弹窗直接展示，绑定真实 series | 设计说明、坐标草图不展示 |
| R3 | 0/50/100% Y 轴与日期 X 轴 | SVG 内可访问文本 | 原型辅助线说明不展示 |
| R4 | 数据点 | circle + title + aria-label | 调试坐标不展示 |
| R5 | 趋势明细表 | 保持现有表格 | 无 |
| R6 | 空态/加载/错误态 | 按现有状态切换 | 不与有数据图表同屏 |

## 3. 前端实现范围映射

| 用户路径 | Vue route | 组件 | 触发动作 | 初始可见 | Playwright 断言 |
| --- | --- | --- | --- | --- | --- |
| 模块列表打开 7 天趋势 | `/modules` | `ModuleTrendDialog.vue` | 点击“7天趋势” | 否 | 接口 days=7、点数等于去重 series、真实标签可见 |
| 模块列表打开 30 天趋势 | `/modules` | `ModuleTrendDialog.vue` | 点击“30天趋势” | 否 | 接口 days=30、日期唯一、图表无重叠 |
| 无趋势数据 | `/modules` | 同组件空态 | 接口 series=[] | 否 | 显示“暂无趋势数据”，不渲染 polyline |

## 4. 图表规格

- SVG `viewBox` 使用稳定固定坐标，不随点位数量改变容器尺寸。
- 绘图区左/右边界固定，Y=100% 位于顶部、Y=0% 位于底部。
- 7 天最多 7 个日期标签；30 天只显示首尾和等距抽样标签，所有 circle 仍完整绘制。
- 图表使用 `group` 角色，数据点使用独立 `img` 角色并保留键盘焦点；点位通过率超出 0..1 时做显示钳制，原始文本仍由表格展示；非法数值不生成 NaN。
- 颜色使用现有 semantic token，不增加装饰性渐变或图形。
